# Сравнение Git и SVN

### 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
- **В Git** ветка — это просто легковесный указатель (текстовый файл размером 41 байт) на конкретный коммит. Создание и переключение ветки происходит мгновенно и не расходует память.
- **В SVN** ветвление реализовано через полное копирование каталога проекта на сервере. Это требует времени, расходует дисковое пространство и нагружает сеть.

### 2. Можно ли в SVN сделать коммит без интернета? Почему?
- **Нет, нельзя.** SVN — это централизованная система контроля версий (CVCS). Любая фиксация (`svn commit`) требует прямого сетевого соединения с центральным сервером. В Git же коммиты делаются в локальный репозиторий на компьютере разработчика полностью автономно.

### 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
- **Хранение огромных бинарных файлов и ассетов** (в GameDev, 3D-моделировании, видеопроизводстве), так как Git медленно работает с большими бинарниками и загружает всю историю целиком.
- **Строгие требования к гранулярному контролю доступа:** в SVN можно ограничить права доступа к отдельным подпапкам внутри одного репозитория (в Git права выдаются только на весь репозиторий целиком).
- **Поддержка старых enterprise- и банковских систем (legacy).**
