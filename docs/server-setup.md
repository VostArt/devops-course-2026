## 8. Веб-сервер Nginx
- **Устанавливаемый пакет:** `nginx` (версия 1.24+ из официального репозитория Ubuntu).
- **Конфигурация ресурса:** `/etc/nginx/sites-available/devops-site` (активирована символической ссылкой в `/etc/nginx/sites-enabled/devops-site`). Стандартный файл `default` отключён.
- **Каталог ресурса:** `/var/www/devops-site`, владелец `devops:devops`, права `755` на каталоги, `644` на файлы.
- **Сертификат и закрытый ключ TLS:**
  - Сертификат: `/etc/ssl/certs/devops.crt` (права `644`, владелец `root:root`);
  - Закрытый ключ: `/etc/ssl/private/devops.key` (права `600`, владелец `root:root`).
- **Срок действия сертификата:** 365 дней (с расширением Subject Alternative Name `DNS:devops.local`).

## 9. Контейнеризация
- **Docker Engine:** Community Edition 27.x, установлен из официального apt-репозитория `download.docker.com`.
- **Группа docker:** пользователь `devops` включён в группу для работы без sudo.
- **Расположение проекта:** `/home/devops/app/`.
- **Файл секретов:** `/home/devops/app/.env` (права `600`, владелец `devops:devops`).
- **Сетевая изоляция:**
  - Внутренняя сеть bridge `backend` для связи `app` и `db`;
  - Порт приложения `5000` опубликован только на адресе `127.0.0.1`;
  - Порт СУБД `5432` закрыт и не публикуется наружу.
- **Хранение данных:** именованный том `app_db_data` (каталог `/var/lib/postgresql/data`).
- **Обратный прокси:** Nginx терминирует TLS на `https://devops.local/app/` и передаёт запросы на `http://127.0.0.1:5000/`.
