
## 9. Контейнеризация
- **Docker Engine:** Community Edition 27.x, установлен из официального apt-репозитория `download.docker.com`.
- **Группа docker:** пользователь `devops` включён в группу для работы без sudo.
- **Расположение проекта:** `/home/devops/app/`.
- **Файл секретов:** `/home/devops/app/.env` (права `600`, владелец `devops:devops`).
- **Сетевая изоляция:**
  - Внутренняя сеть bridge `backend` для связи `app` и `db`;
  - Порт приложения `5000` опубликован только на адресе `127.0.0.1`;
  - Порт СУБД `5432` закрыт и не публикуется наружу.
- **Хранение данных:** именованный том `app_db_data` (каталог `/var/lib/postgresql/data`).
- **Обратный прокси:** Nginx терминирует TLS на `https://devops.local/app/` и передаёт запросы на `http://127.0.0.1:5000/`.
