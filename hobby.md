# Мой пет-проект

Идея: Telegram-бот для автоматического мониторинга доступности игровых серверов.
Стек: Python (aiogram, aiohttp), Docker, SQLite / PostgreSQL.
Цель: научиться писать асинхронный бэкенд, упаковывать его в Docker-контейнер и настраивать автоматический деплой.

Сроки реализации: 1 месяц (к концу семестра).
