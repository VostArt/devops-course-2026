# Сравнение работы с Git: VS Code vs Терминал (CLI)

### Что удобно делать в VS Code (IDE):
1. **Визуальный Diff:** Удобно построчно сравнивать изменения в файлах до коммита с подсветкой синтаксиса.
2. **Разрешение конфликтов слияния:** Наглядный UI с кнопками *Accept Current / Accept Incoming / Accept Both*.
3. **Расширение GitLens:** Мгновенный просмотр истории каждой строки кода (git blame) прямо в редакторе.

### Что удобнее делать в терминале (CLI):
1. **Сложные и низкоуровневые операции:** Интерактивный rebase (`git rebase -i`), управление удаленными репозиториями (`git remote`), работа с stash и написание shell-скриптов для автоматизации.
